# Changelog

All notable changes to **Product MAPS** will be documented in this file.

This project follows semantic versioning in spirit (major/minor/patch), but the primary goal is clarity of changes for real-world users.

## [1.0.0] — 2025-12-17

### Added
- Initial public release of the Product MAPS framework and canonical Product Map template
- Core documentation set explaining how to use MAPS in practice
- Example Product Maps for common scenarios

### Notes
- Product MAPS is the framework name; MAPS is the four-step loop (Mark, Align, Proceed, Sync)
